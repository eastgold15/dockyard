# Dockyard 文档

dockyard 是基于 [elysiax](https://github.com/eastgold15/elysiax) 框架的 docker 部署工具：服务器管理、GitHub/本地项目导入、compose 识别部署、画布编排、反代域名。

## 目录

- [dockyard 实战](./dockyard.mdx)——页面架构在真实项目里的落地：CRUD 页面、纯服务模块、ServiceError、编译分发
- [画布 client 模式](./canvas-client.mdx)——世界地图画布：Solid 整页 client、物理服务器唯一卡、项目透镜过滤

> 框架自身的概念文档（页面架构 L0-L5、逐级降级哲学等）在 elysiax 仓库的 website 里，两边各放各的。
